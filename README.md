# Saber Pro - Versión II

## Descripción
Esta segunda versión de **Saber Pro** presenta un cambio en su arquitectura, pasando de un enfoque monolítico a una arquitectura basada en **microservicios**.

Cada microservicio está diseñado con un modelo hexagonal permitiendo un encapsulamiento de la lógica de negocio y los adaptadores, haciendo que las modificaciones entre peticiones REST o conexiones a terceros sean más fáciles de modificar

## Diagrama de arquitectura C4
Los modelos C4 están disponibles en su versión png y .puml para su extracción y manipulación.
